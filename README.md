# 바로GO — 금천구 출장마사지·홈타이 안내 사이트

서울 금천구 방문형 관리 서비스(출장마사지·홈타이) 정보 안내용 정적 사이트입니다.
`content/` 패키지의 페이지 정의를 읽어 `build.py`가 정적 HTML을 생성합니다.

- 상호: **바로GO**
- 예약 전화: **0508-202-4719** (연중무휴 24시간 상담)
- 메인 키워드: 출장마사지 / 보조 키워드: 홈타이
- 서비스 지역: 서울특별시 금천구 전지역 (가산동·독산동·시흥동)

## 빌드 방법

```bash
python3 build.py
```

빌드 시 자동으로 적용되는 규칙:

- 본문 텍스트 2,000자 미만 페이지는 `robots noindex` 처리
- `sitemap.xml` 에는 index 허용 페이지만 포함
- 공통 안내 블록(`class="pricing"`)은 페이지 고유 본문 글자수 측정에서 제외
- `robots.txt`, `.nojekyll` 자동 생성

배포 전 `content/site.py` 의 `BASE_URL` 을 실제 도메인으로 변경하세요.

## 콘텐츠 운영 원칙 (구글 가이드라인 준수)

- **중복 방지**: 독산1~4동·시흥1~5동은 개별 페이지를 만들지 않고 대표동 페이지에서 세부 생활권으로 통합. 지역명만 바꾼 동일 본문 금지.
- **역세권 처리**: 가산디지털단지역·독산역·금천구청역은 역명 기준 1개 URL. 석수역(안양시 성격)·구로디지털단지역(구로구 성격)은 단독 역 페이지 대신 인접 생활권으로 처리. 신안산선 예정역은 개통 전 단독 색인 미생성.
- **E-E-A-T / 신뢰**: 방문 가능 지역, 예약 가능 시간, 추가 이동비, 결제·취소 기준, 개인정보 처리, 불법·선정적 서비스 불가를 명시. 임의 가격·허위 후기·가짜 체험담 미사용.
- **본문 분량**: 모든 색인 페이지 본문 2,000~2,500자.
- **메타 디스크립션**: 80자 이내.

## 파일 구성

```

content/

  components.py       예약·결제·이동비 안내 블록, 예약 CTA

  areas.py            대표동 허브 + 가산/독산/시흥
  stations.py         역세권 허브 + 5개 역
  districts.py        생활권 허브 + 8개 생활권
  sinansan.py         신안산선 예정 생활권 안내
  info.py             예약·이용 전 확인사항·홈타이 가이드·고객센터·개인정보·약관
  about.py            사이트 소개(Who/How/Why)
assets/               style.css, nav.js, 파비콘/OG 이미지
```
